# Русский OCR для рукописных строк и страниц

Экспериментальная сборка распознавателя рукописного русского текста на основе TrOCR. Можно распознавать отдельную строку или страницу с одной колонкой: в режиме страницы скрипт выделяет строки сверху вниз и распознаёт каждую отдельно. Персональный адаптер скачивается отдельно из GitHub Releases, чтобы не помещать большой бинарный файл в обычную историю Git.

## Установка

Нужен Python 3.10 или новее. В терминале перейдите в эту папку и выполните:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

На Windows вместо команды `source` используйте `.venv\Scripts\activate`.

Скачайте файл [`handwriting-ocr-adapter-v1.safetensors`](https://github.com/susumber1/cs-practice/releases/download/handwriting-ocr-v1/handwriting-ocr-adapter-v1.safetensors) из раздела Releases и сохраните его как `handwriting_dataset/adapter_crossattention.safetensors` рядом с `raspoznat_rukopis.py`.

При первом запуске базовая модель `Kansallisarkisto/cyrillic-large-handwritten` загрузит около 2,44 ГБ весов из Hugging Face. Интернет понадобится для этой загрузки.

## Запуск

Для распознавания одной строки без корректора текста:

```sh
python3 raspoznat_rukopis.py /путь/к/строке.jpg --ocr-only
```

Для страницы с одной колонкой:

```sh
python3 raspoznat_rukopis.py /путь/к/странице.jpg --page --ocr-only
```

Чтобы запустить дополнительную языковую коррекцию, уберите `--ocr-only`. Корректор скачивает ещё одну модель примерно на 383 МБ. Чтобы сравнить результат с базовой OCR-моделью, добавьте `--base-only`.

В режиме `--page` строки выводятся сверху вниз, каждая с новой строки. Модель распознавания загружается один раз и применяется к каждой найденной строке. Корректор тоже загружается один раз и исправляет строки по отдельности. Разделение строк рассчитано на одну колонку; наклонённые снимки, таблицы, несколько колонок, слабый почерк или сложный фон могут снизить точность. Клетки бумаги учитываются при поиске строк, но остаются видимы для OCR-модели.

## О модели

Базовая OCR-модель содержит примерно 611 млн параметров. Адаптер содержит изменения 50,4 млн параметров и был обучен на шести размеченных строках, в три прохода. Это небольшой эксперимент: он может подстроиться под примеры и не гарантирует улучшения распознавания на других фразах. Сами фотографии и тексты для обучения в репозиторий не включены.
