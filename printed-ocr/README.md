# OCR печатного русского текста

Это отдельная программа для распознавания печатного текста на целой странице. Она использует предварительно обученную EasyOCR и не загружает и не меняет модель рукописного текста из папки `handwriting-ocr`.

Поддерживаются фотографии и сканы JPG/JPEG, PNG, HEIC и PDF. PDF обрабатывается постранично: каждая страница преобразуется в изображение и распознаётся той же моделью. В многостраничном результате добавляются номера страниц. Программа выводит строки сверху вниз и объединяет найденные части одной строки. Для нескольких колонок, таблиц и сложной разметки порядок чтения может потребовать ручной проверки.

Если PDF содержит разворот из двух страниц, используйте `--spread`: каждая страница PDF будет разделена пополам, а части распознаны слева направо отдельно.

### Шаблон диплома ЮФУ

Для диплома бакалавра ЮФУ с тем же макетом, что в примере, используйте `--diploma-template`. В этом режиме программа читает только переменные области: вид диплома, ФИО, направление, квалификацию, протокол, серию и номер, регистрационный номер и дату выдачи. Печать, подпись и фоновые элементы не распознаются. Постоянные фразы макета подставляются из шаблона, поэтому результат содержит связный текст диплома.

Это профиль для конкретного макета: полного альбомного разворота диплома бакалавра ЮФУ. Если уверенность OCR ниже порога, рядом с полем появится пометка `[проверьте распознавание]`. Для дипломов другого уровня, вуза или макета потребуется отдельный профиль.

При запуске с `--correct` включается ограниченный словарь дипломных терминов: он исправляет близкие варианты слов «диплом», «бакалавр», «бакалавриат», «магистр», «специалист» и «с отличием». Также известный код направления `09.03.04` позволяет восстановить официальное название «Программная инженерия». Словарь действует только в соответствующих полях шаблона, поэтому не меняет ФИО, даты и номера. Если квалификацию нельзя уверенно сопоставить со списком, программа сохраняет её и добавляет пометку `[проверьте распознавание]`.

Числовые проверки выполняются при каждом запуске с `--diploma-template`: серия состоит из 6 цифр, номер — из 7; регистрационный номер в этом макете имеет вид `XX/XXX`; код направления — `XX.XX.XX`; даты содержат день и четырёхзначный год, а номер протокола — 2 цифры. Если OCR разбил цифры пробелами, программа склеит их и вернёт разделители. Она не подменяет цифры догадками: при неверной длине или формате оставляет OCR-текст и добавляет `[проверьте распознавание]`. С `--correct` исходный текст до нормализации показывается отдельно.

### Коррекция ошибок вторым этапом

Параметр `--correct` включает проверку после OCR. В шаблоне диплома применяются словарь и известные коды, без загрузки большой модели исправления текста. В обычном режиме используется отдельная русскоязычная модель: она сохраняет числовые фрагменты и строки, похожие на ФИО, проверяя остальные слова, включая названия дисциплин рядом с количеством часов. В выходном файле печатаются оба варианта — исходный и после проверки, чтобы результат можно было сверить с изображением.

Для обычного текста используется модель [SAGE FredT5 distilled 95m](https://huggingface.co/ai-forever/sage-fredt5-distilled-95m), обученная исправлять русские орфографические ошибки и опечатки. Её веса занимают около 383 МБ и скачиваются при первом запуске обычного режима с `--correct`; модель работает локально на процессоре и не требует обучения. Корректор может ошибочно переписать фразу, поэтому проверяйте исправленный вариант по исходному изображению.

## Установка на macOS

Откройте Терминал, перейдите в папку `printed-ocr`, затем создайте отдельное окружение и установите зависимости:

```sh
cd /путь/к/cs-practice/printed-ocr
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
```

В отдельном окружении устанавливаются EasyOCR и необходимые библиотеки; файлы и зависимости распознавателя рукописного текста не затрагиваются.

## Оконный интерфейс

После установки зависимостей запустите:

```sh
python3 interface.py
```

В выпадающем списке над файлами доступны четыре раздела: диплом, заграничный паспорт, приложение к диплому и учебный план. В каждом разделе можно выбрать любое количество JPG/JPEG, PNG, HEIC и PDF. В разделе «Учебный план» также доступны файлы DOCX. Добавляйте файлы сразу или частями: одинаковый файл не дублируется внутри раздела. Порядок файлов можно менять, ненужные — удалять. В PDF распознаются все страницы; ограничение числа файлов и страниц в программе не задано.

Для учебного плана в DOCX извлекаются абзацы и таблицы основного содержимого в порядке документа. Строки таблиц выводятся отдельными строками, ячейки разделяются ` | `, абзацы внутри ячейки — ` / `. Визуальная разметка, ширина и объединение ячеек не воспроизводятся; колонтитулы, сноски и комментарии не извлекаются. Word и дополнительные библиотеки не требуются. Для DOCX не загружаются OCR и корректор, даже если включена проверка текста: исходные названия дисциплин и числа сохраняются. Встроенные изображения и объекты обозначаются пометкой; если DOCX содержит только сканы, сохраните его в PDF и добавьте PDF для распознавания. Старый формат `.doc` не поддерживается — пересохраните его в `.docx` или PDF. Поддержка DOCX доступна в оконном интерфейсе для раздела «Учебный план».

Постоянная боковая панель заменена выпадающим списком: он показывает количество файлов каждого раздела. Настройки распознавания собраны в меню «Параметры», а рядом видны включённые режимы. Кнопка «Распознать комплект» обрабатывает все добавленные разделы. Во время обработки параметры заблокированы.

Поля выделены оттенком фона без контрастных рамок, карточки и кнопки скруглены. Тонкие полосы прокрутки появляются при переполнении поля; поддерживаются колесо, перетаскивание бегунка и щелчки по дорожке. Кнопки доступны с клавиатуры: Tab, Enter или пробел; меню закрываются Escape.

По умолчанию используется тёмное оформление. Кнопка «Оформление» открывает настройки: тёмная, графитовая или светлая тема; синий, фиолетовый, бирюзовый или розовый акцент; компактный, обычный или крупный текст. Нажмите «Сохранить», чтобы применить выбор без перезапуска и потери загруженных документов или текста. «Сбросить» выбирает исходное оформление в окне настроек; подтвердите его кнопкой «Сохранить». «Отмена» оставляет текущий вид. Настройки хранятся отдельно от документов в `~/Library/Application Support/PrintedOCR/appearance.json` и восстанавливаются при следующем запуске.

Распознавание объединяет документы в общий текст по разделам, сохраняя порядок файлов внутри каждого раздела и страниц внутри PDF. Текст в поле результата можно редактировать, копировать или сохранить в `.txt` в кодировке UTF-8. Кнопка остановки завершает обработку после текущего файла, включая все его страницы PDF; готовые результаты сохраняются в окне.

Шаблон ЮФУ и проверка текста включены по умолчанию в оконном интерфейсе. Оба режима можно отключить в меню «Параметры». Пункт «Шаблон ЮФУ — только раздел «Диплом»» действует только на раздел «Диплом» и включает описанный выше профиль; числовые поля в нём проверяются автоматически. «Параметры → Проверить текст после распознавания» включает словарь для дипломного шаблона или языковую коррекцию учебных документов. При включённой проверке показывается только исправленный вариант. Строка с цифрами больше не исключается целиком: слова проверяются отдельно, цифровые токены и их разделители сохраняются. Одиночное слово с заглавной буквы проверяется, если рядом нет признаков ФИО. Длинные строки делятся на фрагменты вместо обрезания токенизатором. Определение ФИО остаётся эвристикой; итог следует сверять с документом. В разделе заграничного паспорта языковая правка не применяется, чтобы сохранять распознанные ФИО, транслитерацию и реквизиты.

В оконном интерфейсе OCR распознаёт русский и английский текст. Модели загружаются при первом распознавании и повторно используются до закрытия приложения, поэтому окно открывается до тяжёлой загрузки. Фотографии и PDF паспортов, приложений к диплому и учебных планов обрабатываются как обычный текст: отдельного извлечения паспортных полей и восстановления таблиц нет.

## Словари и сверка комплекта

Проверка текста использует отдельные расширяемые словари в `dictionaries/diploma.json`, `dictionaries/diploma_supplement.json` и `dictionaries/curriculum.json`. Раздел `replacements` содержит конкретные варианты ошибок OCR и правильное написание; `terms` — учебные термины для сопоставления. Например, исправляются «лекцни», «дисциплнны», «самостоятехьная», «отлнчно». Словарь применяется до и после языковой коррекции, только при включённой проверке текста. Паспорт и исходный DOCX словарями не изменяются. После изменения JSON перезапустите приложение.

Параметр **«Сверять документы комплекта»** включён по умолчанию независимо от проверки текста. После обработки файлов в общий результат добавляется **«СВЕРКА КОМПЛЕКТА»**. Отчёт сохраняется и копируется вместе с текстом. В нём указаны подтверждающие файлы, словарные и межфайловые исправления, найденные совпадения и расхождения.

Сверяются явно подписанные ФИО/части имени, дата рождения, код направления, квалификация, серия/номер и дата выдачи диплома. ФИО и квалификация также извлекаются из поддерживаемых фраз шаблона диплома. Паспорт участвует в сверке общих реквизитов, но не исправляется и не считается безусловно верным эталоном. Паспортный номер не сравнивается с номером диплома. В таблицах с явными заголовками «Дисциплина» и «Часы» сопоставляются часы одинаково названных дисциплин; произвольные числовые колонки, оценки и зачётные единицы не смешиваются с часами.

Автоматическая межфайловая замена ограничена учебными терминами из словарей и одной типичной OCR-подменой буквы. Правильное написание должно присутствовать в другом исходном DOCX либо минимум в двух разных исходных файлах из разных разделов. Исправления языковой модели и постоянные фразы шаблона не используются как независимое подтверждение. Один и тот же путь, добавленный в разные разделы, считается одним источником. Содержимое исходных файлов не перезаписывается; текст до словарной/языковой правки обычного OCR сохраняется в памяти результата до следующего запуска распознавания.

Различающиеся цифры, ФИО и неоднозначные сведения остаются исходными, а в отчёте появляется `[ПРОВЕРЬТЕ]` с вариантами и именами файлов. При расхождениях в ФИО или коде направления межфайловые автозамены блокируются: комплект может содержать документы разных людей или программ. Проверка ФИО использует эвристики и не подтверждает личность владельца. Неподписанные реквизиты, латинская транслитерация, MRZ, сложные таблицы и произвольные смысловые противоречия автоматически не сопоставляются. Если общих реквизитов не найдено, отчёт прямо сообщает об этом. При остановке или ошибках файлов сверка помечается неполной.

Проверки реализации запускаются из папки `printed-ocr`:

```sh
.venv/bin/python3 -m unittest discover -s tests -v
```

## Запуск

Вывести распознанный текст в Терминал:

```sh
python3 raspoznat_pechat.py /путь/к/странице.jpg
```

Сохранить текст рядом с изображением в отдельный файл:

```sh
python3 raspoznat_pechat.py /путь/к/странице.heic --output /путь/к/результату.txt
```

Распознать все страницы PDF и сохранить результат:

```sh
python3 raspoznat_pechat.py /путь/к/документу.pdf --output /путь/к/результату.txt
```

Для PDF с разворотом двух страниц:

```sh
python3 raspoznat_pechat.py /путь/к/развороту.pdf --spread --output /путь/к/результату.txt
```

Для диплома бакалавра ЮФУ по шаблону из примера, в том числе из PDF, JPG, PNG или HEIC:

```sh
python3 raspoznat_pechat.py /путь/к/диплому.pdf --diploma-template --output /путь/к/результату.txt
```

Использовать обе модели и сохранить распознанный и исправленный тексты:

```sh
python3 raspoznat_pechat.py /путь/к/диплому.pdf --diploma-template --correct --output /путь/к/результату.txt
```

При первом распознавании EasyOCR автоматически скачает предварительно обученные веса; для этого нужен Интернет. Корректор также скачивает свои веса при первом включении языковой проверки в интерфейсе или запуске с `--correct` в обычном режиме командной строки. Следующие запуски используют уже скачанные файлы.

## Примечания

- Программа рассчитана на печатный текст и не предназначена для распознавания почерка.
- По умолчанию обработка выполняется на процессоре, поэтому большие фотографии могут обрабатываться некоторое время.
- Результат зависит от качества снимка: резкости, освещения, наклона страницы и размера букв.
- В командной строке OCR настроен на русский текст, в оконном интерфейсе — на русский и английский. Сведения об установке и языках см. в [официальном репозитории EasyOCR](https://github.com/JaidedAI/EasyOCR).
