# OCR печатного русского текста

Это отдельная программа для распознавания печатного текста на целой странице. Она использует предварительно обученную EasyOCR и не загружает и не меняет модель рукописного текста из папки `handwriting-ocr`.

Поддерживаются фотографии и сканы JPG/JPEG, PNG, HEIC и PDF. PDF обрабатывается постранично: каждая страница преобразуется в изображение и распознаётся той же моделью. В многостраничном результате добавляются номера страниц. Программа выводит строки сверху вниз и объединяет найденные части одной строки. Для нескольких колонок, таблиц и сложной разметки порядок чтения может потребовать ручной проверки.

Если PDF содержит разворот из двух страниц, используйте `--spread`: каждая страница PDF будет разделена пополам, а части распознаны слева направо отдельно.

### Шаблон диплома ЮФУ

Для диплома бакалавра ЮФУ с тем же макетом, что в примере, используйте `--diploma-template`. В этом режиме программа читает только переменные области: вид диплома, ФИО, направление, квалификацию, протокол, серию и номер, регистрационный номер и дату выдачи. Печать, подпись и фоновые элементы не распознаются. Постоянные фразы макета подставляются из шаблона, поэтому результат содержит связный текст диплома.

Это профиль для конкретного макета: полного альбомного разворота диплома бакалавра ЮФУ. Если уверенность OCR ниже порога, рядом с полем появится пометка `[проверьте распознавание]`. Для дипломов другого уровня, вуза или макета потребуется отдельный профиль.

При запуске с `--correct` включается ограниченный словарь дипломных терминов: он исправляет близкие варианты слов «диплом», «бакалавр», «бакалавриат», «магистр», «специалист» и «с отличием». Также известный код направления `09.03.04` позволяет восстановить официальное название «Программная инженерия». Словарь действует только в соответствующих полях шаблона, поэтому не меняет ФИО, даты и номера. Если квалификацию нельзя уверенно сопоставить со списком, программа сохраняет её и добавляет пометку `[проверьте распознавание]`.

Числовые проверки выполняются при каждом запуске с `--diploma-template`: серия состоит из 6 цифр, номер — из 7; регистрационный номер в этом макете имеет вид `XX/XXX`; код направления — `XX.XX.XX`; даты содержат день и четырёхзначный год, а номер протокола — 2 цифры. Если OCR разбил цифры пробелами, программа склеит их и вернёт разделители. Она не подменяет цифры догадками: при неверной длине или формате оставляет OCR-текст и добавляет `[проверьте распознавание]`. С `--correct` исходный текст до нормализации показывается отдельно.

### Коррекция ошибок вторым этапом

Параметр `--correct` включает проверку после OCR. В шаблоне диплома применяются словарь и известные коды, без загрузки большой модели исправления текста. В обычном режиме используется отдельная русскоязычная модель: она сохраняет строки с цифрами и строки, похожие на ФИО. В выходном файле печатаются оба варианта — исходный и после проверки, чтобы результат можно было сверить с изображением.

Для обычного текста используется модель [SAGE FredT5 distilled 95m](https://huggingface.co/ai-forever/sage-fredt5-distilled-95m), обученная исправлять русские орфографические ошибки и опечатки. Её веса занимают около 383 МБ и скачиваются при первом запуске обычного режима с `--correct`; модель работает локально на процессоре и не требует обучения. Корректор может ошибочно переписать фразу, поэтому проверяйте исправленный вариант по исходному изображению.

## Установка на macOS

Откройте Терминал, перейдите в папку `printed-ocr`, затем создайте отдельное окружение и установите зависимости:

```sh
cd /путь/к/cs-practice/printed-ocr
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install -r requirements.txt
```

В отдельном окружении устанавливаются EasyOCR и необходимые библиотеки; файлы и зависимости распознавателя рукописного текста не затрагиваются.

## Оконный интерфейс

После установки зависимостей запустите:

```sh
python3 interface.py
```

В боковой панели доступны пять разделов: диплом, заграничный паспорт, приложение к диплому, учебный план и дополнение к паспорту. В каждом разделе можно выбрать любое количество JPG/JPEG, PNG, HEIC и PDF. Добавляйте файлы сразу или частями: одинаковый файл не дублируется внутри раздела. Порядок файлов можно менять, ненужные — удалять. В PDF распознаются все страницы; ограничение числа файлов и страниц в программе не задано.

Распознавание объединяет документы в общий текст по разделам, сохраняя порядок файлов внутри каждого раздела и страниц внутри PDF. Текст в поле результата можно редактировать, копировать или сохранить в `.txt` в кодировке UTF-8. Кнопка остановки завершает обработку после текущего файла, включая все его страницы PDF; готовые результаты сохраняются в окне.

Флажок «Диплом ЮФУ по шаблону» действует только на раздел «Диплом» и включает описанный выше профиль; числовые поля в нём проверяются автоматически. «Проверить текст после распознавания» включает словарь для дипломного шаблона или языковую коррекцию учебных документов. При включённой проверке показывается только исправленный вариант. В разделах паспорта и дополнения к нему языковая правка не применяется, чтобы сохранять распознанные ФИО, транслитерацию и реквизиты.

В оконном интерфейсе OCR распознаёт русский и английский текст. Модели загружаются при первом распознавании и повторно используются до закрытия приложения, поэтому окно открывается до тяжёлой загрузки. Паспорта, приложения к диплому и учебные планы обрабатываются как обычный текст: отдельного извлечения паспортных полей и восстановления таблиц нет.

## Запуск

Вывести распознанный текст в Терминал:

```sh
python3 raspoznat_pechat.py /путь/к/странице.jpg
```

Сохранить текст рядом с изображением в отдельный файл:

```sh
python3 raspoznat_pechat.py /путь/к/странице.heic --output /путь/к/результату.txt
```

Распознать все страницы PDF и сохранить результат:

```sh
python3 raspoznat_pechat.py /путь/к/документу.pdf --output /путь/к/результату.txt
```

Для PDF с разворотом двух страниц:

```sh
python3 raspoznat_pechat.py /путь/к/развороту.pdf --spread --output /путь/к/результату.txt
```

Для диплома бакалавра ЮФУ по шаблону из примера, в том числе из PDF, JPG, PNG или HEIC:

```sh
python3 raspoznat_pechat.py /путь/к/диплому.pdf --diploma-template --output /путь/к/результату.txt
```

Использовать обе модели и сохранить распознанный и исправленный тексты:

```sh
python3 raspoznat_pechat.py /путь/к/диплому.pdf --diploma-template --correct --output /путь/к/результату.txt
```

При первом распознавании EasyOCR автоматически скачает предварительно обученные веса; для этого нужен Интернет. Корректор также скачивает свои веса при первом включении языковой проверки в интерфейсе или запуске с `--correct` в обычном режиме командной строки. Следующие запуски используют уже скачанные файлы.

## Примечания

- Программа рассчитана на печатный текст и не предназначена для распознавания почерка.
- По умолчанию обработка выполняется на процессоре, поэтому большие фотографии могут обрабатываться некоторое время.
- Результат зависит от качества снимка: резкости, освещения, наклона страницы и размера букв.
- В командной строке OCR настроен на русский текст, в оконном интерфейсе — на русский и английский. Сведения об установке и языках см. в [официальном репозитории EasyOCR](https://github.com/JaidedAI/EasyOCR).
