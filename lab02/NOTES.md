рабочая папка это файлы проэкта на моем пк
индекс это буфер для готовых к сохранению файлов
коммит это постоянная фиксация файлов
git локальный а github внешний

<<Использованные команды>>
git status выводит название текущей версии
git diff показывает что небыло добавлено через add
git diff --staged показывает готовые к отправке изминения

<<Ветки>>
ветка - это независимая линия разработки 
при новом коммите указатель ветки смещается на новый коммит
слияние объединяет историю и изменения из одной ветки в другую
